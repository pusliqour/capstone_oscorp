# Remaining Jiran work

The functional team demo, account/product management, SVG icons, local Studio and isolated ZIP recovery are implemented. This list describes what still needs work; the GRC task board tracks the same priorities.

1. **Stable hosting and startup.** Replace the temporary tunnel/laptop dependency with a stable backend or named tunnel/domain. Add a reliable startup/health-check process, backup and recovery procedure. Current services depend on this Mac staying online.
2. **Confirm data provenance and intended use.** The original three-store Excel source is still unverified. The recovered 50-store archive is explicitly generated. The user has now authorized archive use: 50 labelled synthetic archive stores and a read-only explorer are connected to the app. Real-data authenticity still needs confirmation before any real-world research claims.
3. **Fix research-model edge behavior.** The archive classifier scores highly against policy labels but failed all tested 365-day-inactivity cases. Add explicit out-of-distribution/abstention handling or training-only augmentation, and rerun group/time-aware tests. Do not claim independent business accuracy or replace the current live model merely because synthetic F1 is high.
4. **Independent evaluation and forecasting.** Collect additional real stores, dated stock snapshots and retailer-reviewed outcomes. Reserve new stores/time periods for final testing; assess sparse demand, large errors and uncertainty calibration. The existing archive development split has already been inspected.
5. **Finish small application gaps.** Imported/manual inventory Refresh now reloads records without calling POS sync. Extend unsaved-edit protection to browser Back. Run a full public-site management browser test after the consolidated-path checks.
6. **Restore optional integrations only when available.** Square/Apideck connector credentials and backend services need separate activation and tests. Managed email changes, full login-account deletion, multiple stores per account and uploaded-document management are not implemented in this team demo.
7. **Research-paper and UX evidence.** Run participant usability tasks and record completion, errors and feedback. Finalize authorship/contact/template/venue decisions and update the paper with reproducible, appropriately qualified results. A functional prototype and passing checks are not a participant study or publication acceptance.
8. **Retire compatibility links later.** The source and related material are consolidated now, with old paths preserved as symlinks. Gradually update remaining virtual-environment, historical document and runtime path references, then test before removing links. Historical files were retained rather than deleted.

See `improvements.md` for completed improvements, `updates.md` for implementation history, `docs/ML_CHANGES.md` for the main model, and `docs/ARCHIVE_RECOVERY.md` for the separate generated research dataset.
