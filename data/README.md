# Data recovery boundary

The original hosted Supabase hostname does not resolve as of 24 October 2026. No historical database records were recovered during this pass.

- `incoming/`: operator-supplied exports from ERPNext, Odoo, Square, spreadsheets, or other systems (Git-ignored).
- `normalized/`: local normalized inventory/sales files (Git-ignored).
- `data-status.json`: public, non-sensitive statement of what is and is not known.

Use the tested source-neutral normalizer:

```bash
python3 tools/resource_import.py \
  --source erpnext \
  --input data/incoming/erpnext-stock.csv \
  --output data/normalized/jiran-inventory.csv
```

Supported sources are `erpnext`, `odoo`, and already-normalized `jiran` CSV. The normalized contract contains factual resource fields only: SKU, name, category, quantity, price, currency, and location.

No AI result is generated by this adapter. AI fields remain null until a traceable dataset is supplied, a training run is reproduced, and evaluation metrics are recorded.
